# AGENTS.md

## О проекте

Проект: Сайт церкви «Слово Жизни».

Главная цель проекта — создать современный, простой и дружелюбный сайт с удобной CMS.

---

## Главные принципы

1. Простота важнее количества функций.
2. Любой раздел должен быть понятен новому пользователю.
3. Mobile First.
4. Минимализм.
5. Высокая доступность.
6. Все данные должны редактироваться через CMS.
7. Любой модуль можно отключить.
8. Не создавать сложные решения, если есть простые.

---

## Дизайн

Использовать только дизайн-систему проекта.

Никаких случайных цветов.

Никаких случайных компонентов.

---

## Код

Писать чистый TypeScript.

Следовать принципам SOLID там, где это оправдано.

Не дублировать код.

Использовать серверные компоненты Next.js там, где это возможно.

---

## UI

Не использовать всплывающие окна без необходимости.

Все формы должны быть максимально простыми.

Минимум кликов.

Максимум понятности.

---

## Комментарии

Если решение неоднозначное — объясни его комментариями в коде.
